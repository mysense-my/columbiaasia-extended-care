# Columbia Asia Extended Care Hospital Shah Alam: landing page

Static landing page (HTML, CSS, JS) for extended care and rehabilitation at Columbia Asia Extended Care
Hospital Shah Alam. No build step is needed to view it: serve this folder and open `index.html`.

```
python3 -m http.server 8000
```
